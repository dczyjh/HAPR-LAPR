# 冻结实验协议概览

本说明用于查找代码，不代替各路线的实际 resolved 配置和来源 SHA。层号均为从 0 开始。

| 项目 | HARP | LARP |
| --- | --- | --- |
| 主方法位置 | 视觉块 8–11，非线性瓶颈 | 视觉块 8–11，注意力输出投影 O |
| 主容量 | 瓶颈宽 32，新增 199,808 参数 | rank 2，新增 12,288 参数 |
| 初始化/尺度 | 零输出起点，前向尺度 0.001，fix2 指定 VJP | B 零初始化，alpha=1，alpha/sqrt(rank) |
| 新增组更新 | 实际 fix2 补偿及冻结/渐升规则 | 普通 FP16 SGD，共同学习率的 0.1 倍 |
| memory-efficient attention | 关闭 | 开启 |
| 结构消融 | 中四层宽32；后四层宽16/64 | 后四层rank1/4；末三层rank2 |

两路线均保留视觉提示、语义投影器和提示蒸馏基础结构；教师为 ViT-L/14，学生为 ViT-B/16。共同可训练部分参数数为 1,013,760。公共投影器采用实际第 2 轮逐 batch 渐升规则；不把该规则与 HARP 新增组的更新规则混为一谈。

共同设置为 seed 1/2/3、20 轮、训练 batch 8、测试 batch 100、8 个数据加载 worker、FP16。Aircraft、Flowers、DTD 的 KD 权重为 200，其余七集为 1000。主实验没有 RP、额外 KL、FP32 主副本或按数据集拼接最优变体。

十集键：`caltech101`、`stanford_cars`、`sun397`、`oxford_pets`、`eurosat`、`ucf101`、`fgvc_aircraft`、`oxford_flowers`、`dtd`、`food101`。不含 ImageNet。训练使用 Base 与 Novel 的无标签图像；学生蒸馏目标不使用其分类标签。

## 评价和对照

沿用实际训练的 Base 测试准确率选 best 规则，不能改称独立验证集选点。Base、Novel 与 HM 来自同一选定检查点；不同 seed 分别计算 HM，再进行三 seed 汇总，不将“先平均 Base/Novel 再算 HM”混作同一统计量。

R0 是原框架复现实验的外部参照，R1 是相应路线的公共训练结构控制。HARP 与 LARP 后端不同，应首先比较各自匹配 R1，不把跨路线 R1 或跨机器运行自动视为数值等价。保留原始 CPU/工程步门槛、保存/首次独立重载与停止规则；这个 Git 整理过程没有放宽它们。

便携入口已接入全新初始化、匹配输入/LR、原优化器/调度、真实四步门槛、保存/首次独立重载；本地合成CPU执行链已验证，完整CUDA模型尚未在本轮重新验收。正式启动会逐项检查，而非跳过这些条件。各工程的职责及对照用途见[工程用途总览](PROJECT_MAP.md)，当前验收范围见[验证说明](VALIDATION.md)。
