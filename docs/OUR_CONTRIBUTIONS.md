# 本项目的研究贡献与实验价值

本项目研究的是：在固定教师、使用无标签图像的提示蒸馏框架中，如何通过学生视觉侧的少量新增参数改善基类识别与新类泛化的综合表现。**贡献是两条具体的视觉适配方案，以及对其收益条件的系统实验分析**；不是提出通用 Adapter、LoRA 或原提示蒸馏算法，也不是把三个参考方法完整叠加。

## 1. 高层非线性残差适配：HARP

在保留原视觉提示和语义投影器的基础上，构建学生高层视觉编码块中的非线性瓶颈残差分支，使蒸馏训练可以直接调整高层视觉表示。主方案采用后四层、宽度32、零输出初始化，并实现与小残差及FP16计算相配套的fix2指定反向和分组启动规则。新增结构不改变原KD目标，不引入额外表示约束。

这项工作的具体贡献，是将高层瓶颈适配组织为可执行、可核查的提示蒸馏方案，并通过匹配控制检验完整配置的识别收益。它借鉴MMA的高层适配思路，但没有采用完整MMA的文本适配器或共享跨模态投影。通用瓶颈结构本身不作为本项目原创。

实验显示该路线在多个任务上有实际收益，其中Aircraft和DTD的Base、Novel与HM在三个seed中均高于本路线匹配R1。位置与宽度对照进一步说明收益具有任务依赖，固定主宽度32不等于精度最优；更大宽度也没有消除所有训练波动。结论针对完整实现组合，不能拆成尚未独立消融的“fix2、暂缓更新或渐升各自必然涨分”。完整数值、报告口径及边界见[HARP实验发现](HARP_FINDINGS.md)。

## 2. 低秩注意力输出适配：LARP

在同一类提示蒸馏设置下，构建仅作用于学生视觉注意力输出投影O的低秩权重增量。主方案限定后四层、rank2，冻结原Q/K/V和骨干权重，保留原多头注意力计算路径，以零增量初始化和普通FP16 SGD联合训练原提示、投影器及新增低秩参数。主方案仅增加12,288个参数，不叠加HARP或额外参考损失。

这项工作的具体贡献，是将低秩适配限定到蒸馏学生的高层输出映射，形成与瓶颈分支不同的参数更新路线，并检验这种较小新增预算下的识别效果。CLIP-LoRA提供低秩适配的应用参考；本项目不是完整复制其少样本分类协议，也不把LoRA分解或缩放公式本身作为原创。

实验显示该路线在七个数据集的三seed平均HM上同时高于R0与本路线R1，Cars的三项指标三个seed均提高，Flowers的Novel与HM三个seed均提高。这证明存在有数据支持的任务收益，但十集宏平均HM仍低于R1，不能概括为整体平均或普适优势。rank与层集合对照揭示预算和任务响应的取舍，不据消融高值事后更换主方法。完整数值与限制见[LARP实验发现](LARP_FINDINGS.md)。

## 3. 收益条件与配置选择的实验分析

分别为两条路线保留原框架复现参考R0和匹配公共执行条件的控制R1，完成十个数据集、三个seed的主比较及既定结构消融。HARP通过等新增预算的位置对照和宽度对照分析非线性适配；LARP通过rank及层集合对照分析低秩更新。Base、Novel、逐seed HM、均值与离散性共同报告，不以单次最好seed代替总体结果。

实验分析的贡献不只是列出涨分：它明确了哪些任务有较一致的收益、收益来自基类还是新类、减少或增加预算如何影响结果，以及为什么较低蒸馏损失、较好的best分数和更平稳的训练过程并不等价。完整轨迹与负结果帮助限定方法适用条件，也为后续结构选择提供实际依据。缩放、初始化、容量和部分节点来源的耦合仍保留，不能把全部结构对照写成纯单因素因果证明。

这些分析与两条方法一起构成研究成果；不另包装成第三个融合算法，也不据方向性提升数自动宣称统计显著、机制已证或训练/推理加速。

## 4. 工程交付与学术贡献分开
