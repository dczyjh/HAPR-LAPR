# 代码与验证范围

## 当前交付

已提供独立 `plan/run/evaluate`、原始 R0、两路线 R1/主方法/结构消融、外部物料来源与 SHA 检查、全新初始化、每角色四步门槛、20 轮原训练循环、best/last 审计、首次独立重载和三 seed 结果汇总。便携运行器不要求已有实验的 bridge 张量、旧 R1 输入记录或服务器输出目录。

冻结 `archive/vendor` 内容只读保留；正式执行通过 `reproduce.py` 加载其科学实现，再接入原调度函数与核验。不要直接调用早期 v3 默认脚本、旧服务器 worker 或底层 `train.py` 代替最终协议。

## 本地已验证

逐文件 SHA、Python/JSON 语法、全部配置、原科学函数 AST、框架的仅导入和 Yacs 配置合并、参数化/VJP/SGD/双渐升及初始化映射已检查。CPU 小型集成测试还执行了原 TrainerBase 训练循环和 SimpleTrainer 选 best 行为、配对输入/LR、20 轮轨迹、best/last 与原 evidence 模块的首次独立重载。输入漂移和超出重载硬限的反例必须失败并留下第一份证据；不允许二次评估覆盖。

这些 CPU fixture 是合成工程测试，不属于论文数据、不证明完整 FP16 CLIP 稳定或分数复现。当前通过项、测试数量及跳过项以 [validation_report.json](../metadata/validation_report.json) 为准；历史各 route 的旧报告仍是上阶段回执，不冒充本轮总验收。R0 完整官方框架的仅导入测试因本地缺 `wilds` 跳过，该依赖已在正式版本锁中登记；其真实 defaults/extend_cfg 配置合并和单组 SGD 透明性已单独验证。

## 未执行的验证

本轮未连接服务器、下载整套大物料、安装新的 Linux 环境、调用 CUDA CLIP 模型、训练或重评真实数据集。现有环境版本锁是历史身份记录，不是软件源今天一定可安装的保证。项目可用实际物料执行，但不能声称本次发布已经独立重现了历史准确率。

## 真正运行时的约束

启动核源码与固定配置、实际 CLIP/教师 SHA、固定划分大小/SHA、原读取器的有序成员/类别/计数及图像路径。训练前各角色四步检查原更新、冻结权重/教师不变、保存恢复和 R1 零分支首步一致；只有通过后才进入正式 20 轮。图片存在和划分身份不等于全部图片的历史字节证明；来源与限制见物料说明。

每轮按 Base 严格提高选 best，同值保留最早轮；这是 Base-test 选点，不是独立验证集。训练结束后的 native 与首次独立重载保持原对称行尺度硬界 `0.002 + 0.002 * max(两次该行绝对最大值)`。第一份重载指标先保存，硬检查失败不择优重测、不改成 passed。

任何步骤失败均保存错误/日志和可取得的模型、优化器、梯度、输入及 RNG；停止后继，无自动修参、续训或循环重试。既有实验结果未被本次工程测试改写。
