Use `../cli.py plan` and `../cli.py check`; portable training is explicitly blocked until the original scientific controls are wired and validated.

No login credentials, datasets, model checkpoints, initialized trainable tensors or environment binaries are included. The tokenizer BPE vocabulary and original license texts are supplemental code resources, identified separately in the source inventory. Extra worker files are explicitly distinguished from the 341-entry scientific manifest.
